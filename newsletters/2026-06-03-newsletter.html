How to Use Claude Code's Dynamic Workflows

Dynamic workflowsAI systems that automatically coordinate multiple agents to handle complex, multi-step tasks represent Claude Code's biggest leap toward true agentic programming. Here's how to put them to work:

Getting Started: Switch on the new "ultracode" setting through the effort menu, which sets effort to xhigh while letting Claude automatically decide when to use workflows. This replaces the old "workflow" trigger keyword.

Best Use Cases: Think codebase-wide operations: security audits where Claude searches a service in parallel, then runs independent verification on findings. Large migrations and modernization efforts work well too—framework swaps, API deprecations, and language ports spanning thousands of files.

Managing Runs: Use /workflows to manage active runs. Each workflow creates an orchestration script that coordinates subagents working different parts of your task. You'll see progress as agents complete their sections and coordinate results.
