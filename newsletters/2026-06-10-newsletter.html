Anthropic Product News

Claude Fable 5 Launches: The New Frontier Model

Anthropic announced Claude Fable 5 and Claude Mythos 5 on June 9, marking the first models in the new Mythos-class tier above Opus. Claude Fable 5 is the generally available model with state-of-the-art results on nearly all tested benchmarks, running with always-on adaptive thinking, a 1-million-token context window, and 128K output tokens.

The safety angle is notable: Fable 5 includes safety classifiers that automatically fall back to Claude Opus 4.8 for flagged requests in domains such as cybersecurity and biology, while Claude Mythos 5 shares the same capabilities without the safety classifiers and is offered only in limited availability through Project Glasswing.

The model is available to Pro, Max, and Enterprise customers at no extra charge until June 22, after which pricing will be based on usage. Fable 5 uses tokens at a much faster rate than previous Claude models.

Claude Code Gets Dynamic Workflows

Claude Code introduced dynamic workflows through a new "ultracode" setting that lets Claude decide automatically when to use workflows for handling tasks. Early access users have been using dynamic workflows for codebase-wide bug hunts, security audits, and large migrations.

The same approach works for hardening passes like auth checks and input validation across entire codebases, plus large migrations including framework swaps and API deprecations spanning thousands of files.

Project Glasswing Expands

Anthropic is expanding Project Glasswing, extending the partnership to approximately 150 new organizations following several weeks of collaboration with security industry partners, open-source software maintainers, and the US government. Initial partners have been deploying the model to scan codebases for vulnerabilities, finding more than 10,000 high- or critical-severity security flaws.

Managed Agents Go Scheduled

Claude Managed Agents can now run on a schedule and securely access CLI tools and other authenticated services. Both features are available in public beta on the Claude Platform, with agents able to complete routine work automatically using cron schedules.

Feature Deep-Dive

Understanding Claude Fable 5's Adaptive ThinkingAI that automatically adjusts its reasoning approach based on the task

Claude Fable 5's most distinctive feature is "always-on adaptive thinking." Unlike previous models where you had to explicitly request deeper reasoning, Fable 5The public version of Claude's Mythos-class model automatically shifts into different thinking modes based on the complexity of your request.

Here's how to make the most of it:

For coding tasks: Ask for complete implementations rather than snippets. Fable 5 will automatically analyze dependencies, consider edge cases, and structure the code for maintainability without you needing to specify these requirements.

For research: Instead of asking for bullet points, request comprehensive analysis. The model will automatically cross-reference sources, identify gaps, and provide nuanced conclusions.

For creative work: Give open-ended prompts. Fable 5 will explore multiple angles, consider audience and tone, and iterate on ideas internally before presenting options.

The key difference: users should use Fable 5 in standard conversation mode rather than Workflow with high effort settings during the free period, as the latter can quickly exhaust daily limits. The adaptive thinking handles the heavy lifting automatically.
