Feature Deep-Dive

Dynamic Workflows: Your Personal AI Army

Dynamic workflows represent the biggest leap in AI capability since computer use. Instead of one AI handling one task, the system allows a lead AI agent to plan, delegate, and coordinate work across hundreds of parallel subagents.

How it works:

Claude receives a task prompt and writes a JavaScript orchestration script on the fly. A separate runtime executes that script in the background, spinning up multiple subagents that work in parallel, supporting up to 16 concurrent agents and a total cap of 1,000 agents per run.

Getting started:

Switch on the new "ultracode" setting in Claude Code through the effort menu. This sets effort to xhigh while letting Claude decide automatically when to use a workflow. For Max or Team users, dynamic workflows are on by default—just ask Claude to create a workflow.

Best use cases:

Think tasks too large for one conversation to coordinate: codebase-wide security audits, large framework migrations, or any work where you need independent verification of results. When the cost of a wrong answer is high, a workflow gives Claude independent attempts at the problem and adversarial verification.

Enterprise users should note that dynamic workflows are off by default at launch—your admin can enable them in Claude Code settings.
